Udacity _Beaver's Choice Paper Company_ project: Pydantic AI multi-agent system that handles inventory, quoting, and sales for a paper company, using SQLite and sample customer requests.

Setup with [uv](https://docs.astral.sh/uv/): `uv venv && source venv/bin/activate && uv pip install -r requirements.txt`

Add your API keys to a `.env` file: `OPENAI_API_KEY=your_key`, `OPENAI_BASE_URL=https://openai.vocareum.com/v1`

Then run the multi-agent system with `python beaver_pydantic_ai.py` (evaluates sample quote requests and writes `test_results.csv`).
